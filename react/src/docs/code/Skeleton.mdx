# Skeleton: React and Angular

Same component, both frameworks. Live previews are under **Components / Skeleton** (React) and **Angular / Skeleton**.

## React

```tsx
import { Skeleton } from '@bounteous/ui'
```

```tsx
<Skeleton className="h-4 w-48" />
<Skeleton className="size-12 rounded-full" />
```

## Angular (ZardUI)

```ts
imports: [ZardSkeletonComponent]  // from '@/shared/components/skeleton'
```

```html
<z-skeleton class="h-4 w-48" />
<z-skeleton class="size-12 rounded-full" />
```
