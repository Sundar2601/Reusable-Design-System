# Android Segmented Button: React and Angular

Same component, both frameworks. Live previews are under **Mobile / Android / Segmented Button** (React and Angular).


```tsx
<AndroidSegmentedButton
  options={[{ value: "day", label: "Day" }, { value: "week", label: "Week" }, { value: "month", label: "Month" }]}

  onValueChange={setRange}
```
