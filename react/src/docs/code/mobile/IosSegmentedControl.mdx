# iOS Segmented Control: React and Angular

Same component, both frameworks. Live previews are under **Mobile / iOS / Segmented Control** (React and Angular). Hand-built Apple HIG replica using the theme tokens, so it follows light and dark. Tint is overridable with `--ios-tint`.

## React

```tsx
import { IosSegmentedControl } from '@bounteous/ui'
```

```tsx
<IosSegmentedControl
  defaultValue="week"
  options={[{ value: 'day', label: 'Day' }, { value: 'week', label: 'Week' }]}
  onValueChange={(v) => console.log(v)}
/>
```

## Angular

```ts
imports: [IosSegmentedControlComponent]  // from '@/shared/extended/ios-segmented-control.component'
```

```html
<ios-segmented-control [options]="options" [(value)]="range" />
```
