# Separator: React and Angular

Same component, both frameworks. Live previews are under **Components / Separator** (React) and **Angular / Separator**.

## React

```tsx
import { Separator } from '@bounteous/ui'
```

```tsx
<Separator />
<Separator orientation="vertical" />
```

## Angular (ZardUI)

```ts
imports: [ZardSeparatorComponent]  // from '@/shared/components/separator'
```

```html
<z-separator />
<z-separator zOrientation="vertical" />
```
