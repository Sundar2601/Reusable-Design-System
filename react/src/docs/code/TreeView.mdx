# Tree View: React and Angular

Same component, both frameworks. Live previews are under **Components / Tree View** (React) and **Angular / Tree View**. This is an extended component (beyond shadcn), hand-built in both.

## React

```tsx
import { TreeView } from '@bounteous/ui'
```

```tsx
<TreeView
  nodes={[{ id: 'src', label: 'src', children: [{ id: 'main', label: 'main.tsx' }] }]}
  defaultExpanded={['src']}
  onSelect={(id) => console.log(id)}
/>
```

## Angular

```ts
imports: [TreeViewComponent]  // from '@/shared/extended/tree-view.component'
```

```html
<ui-tree-view [nodes]="nodes" [defaultExpanded]="['src']" [(selected)]="selectedId" />
```
