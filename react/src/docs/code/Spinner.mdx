# Spinner: React and Angular

Same component, both frameworks. Live previews are under **Components / Spinner** (React) and **Angular / Spinner**.

## React

```tsx
import { Spinner } from '@bounteous/ui'
```

```tsx
<Spinner />
<Spinner className="size-6" />
```

## Angular (ZardUI)

```ts
imports: [ZardSpinnerComponent]  // from '@/shared/components/spinner'
```

```html
<z-spinner />
<z-spinner class="size-6" />
```
