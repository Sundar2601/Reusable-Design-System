# Progress: React and Angular

Same component, both frameworks. Live previews are under **Components / Progress** (React) and **Angular / Progress**.

## React

```tsx
import { Progress } from '@bounteous/ui'
```

```tsx
<Progress value={60} />
```

## Angular (ZardUI)

```ts
imports: [ZardProgressComponent]  // from '@/shared/components/progress'
```

```html
<z-progress [value]="60" />
```
