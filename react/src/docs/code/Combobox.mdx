# Combobox: React and Angular

Same component, both frameworks. Live previews are under **Components / Combobox** (React) and **Angular / Combobox**.

## React

```tsx
import { Combobox } from '@bounteous/ui'
```

```tsx
const options = [
  { value: 'next', label: 'Next.js' },
  { value: 'remix', label: 'Remix' },
]

<Combobox options={options} placeholder="Select framework..." onValueChange={setValue} />
```

## Angular (ZardUI)

```ts
imports: [...ZardComboboxImports]  // from '@/shared/components/combobox/combobox.imports'
```

```html
<z-combobox [options]="options" placeholder="Select framework..." [(zValue)]="value" />
<z-combobox [options]="options" zInvalid />
<z-combobox [options]="options" zDisabled />
```
